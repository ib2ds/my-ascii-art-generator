# ASCII Art Generator

A simple Flask web application to generate ASCII art from user-provided text and a selected font.

## Installation

1.  Clone this repository:
    ```bash
    git clone <repository-url>
    ```
2.  Navigate to the project directory:
    ```bash
    cd ascii-art-generator
    ```
3.  Install the dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## Usage

1.  Run the Flask application:
    ```bash
    python app.py
    ```
2.  Open your web browser and navigate to:
    ```
    http://127.0.0.1:5000/
    ```
3.  Enter your desired text, select a font, and click "Generate ASCII Art".

## Dependencies

This project uses the following Python libraries:

*   [Flask](https://flask.palletsprojects.com/): A lightweight WSGI web application framework.
*   [art](https://pypi.org/project/art/): A library for creating ASCII art.
